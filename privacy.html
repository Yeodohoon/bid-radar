bid-radar 개인정보처리방침

시행일: 2026-11-11 · 개인 사용 도구

bid-radar(이하 "본 도구")는 개발자 본인만 사용하는 개인 자동화 도구입니다. 본 방침은 본 도구가 Google 계정 정보를 어떻게 다루는지 설명합니다.

1. 이용 대상

본 도구는 개발자 본인만 사용하며, 다른 이용자를 받지 않습니다.

2. 접근하는 Google 데이터

  • 본인 계정의 기본 정보(이메일 주소, 이름): 인증 확인에만 사용합니다.
  • Google 스프레드시트·드라이브: 본인이 지정한 스프레드시트에 공고 검토 결과를 읽고 쓰는 데에만 사용합니다.

3. 이용 목적

공개된 공공 입찰·지원사업 공고를 정리하여 본인 스프레드시트에 기록하는 목적 외에는 사용하지 않습니다.

4. 보관 및 제3자 제공

  • 인증 토큰은 본인 컴퓨터에 암호화하여 저장합니다.
  • Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고에 사용하지 않습니다.
  • 본 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 접근 철회

언제든지 Google 계정 권한 페이지에서 본 도구의 접근 권한을 해제할 수 있습니다.
